A hand-drawn front page of Monday 23 November 2026's world news: a huge date, six card stories with original pictograms (COP31, Ukraine off Libya, Hormuz, the AI market rout, the Indonesia factory fire and Ebola-hit DR Congo) and a short "also today" strip. The committed `entry.png` is copied to `/output/entry.png` by `main.py`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The artwork is drawn by `render.py` during development; the graded program only copies the committed PNG, so both runs write identical bytes.
